# โปรแกรมใบเสร็จรับเงินค่าเช่า — ออฟไลน์ + สำเนาออนไลน์

## ใช้งานออฟไลน์

- โปรแกรมบันทึกข้อมูลใน `localStorage` ของเบราว์เซอร์ก่อนเสมอ แม้ไม่มีอินเทอร์เน็ต
- บันทึกเสร็จแล้วใบเสร็จจะล็อกทันที เรียกดูย้อนหลังและพิมพ์ต้นฉบับ + สำเนาได้ในขนาด 17.5 × 8.8 ซม. บน A4
- เมื่อเปิดเว็บไซต์บน **GitHub Pages ผ่าน HTTPS อย่างน้อยหนึ่งครั้งขณะออนไลน์** service worker จะเก็บหน้าเว็บไว้เพื่อเปิดอีกครั้งแบบออฟไลน์ในเบราว์เซอร์และอุปกรณ์เดิม (ขึ้นอยู่กับนโยบายเก็บแคชของเบราว์เซอร์)
- เปิด `index.html` จากไฟล์ในเครื่องก็ใช้งานออฟไลน์ได้ แต่จะไม่มี service worker จึงไม่ซิงก์จนมีอินเทอร์เน็ต
- การล้างข้อมูลเว็บไซต์ การเปลี่ยนเครื่อง หรือโหมดไม่ระบุตัวตนอาจทำให้ประวัติในเครื่องสูญหาย ให้ใช้ปุ่ม **สำรองข้อมูล (.json)** เป็นระยะ
- เมื่อกลับมาออนไลน์และมีการเข้าสู่ระบบ Supabase โปรแกรมจะพยายามซิงก์รายการที่ค้างโดยอัตโนมัติ หรือกด **เรียกคืน/ซิงก์สำเนา** เองได้
- หากยังไม่ได้ตั้งค่า Supabase สามารถออกและพิมพ์ใบเสร็จออฟไลน์ได้ตามปกติ แต่สำเนาจะยังไม่ถูกส่งขึ้นคลาวด์

## เปิดเก็บสำเนาออนไลน์ (Supabase)

1. สร้างโครงการที่ https://supabase.com
2. รัน `supabase_schema.sql` ใน SQL Editor หนึ่งครั้ง (ตรวจตารางเดิมก่อนรันซ้ำ)
3. คัดลอก Project URL และ **publishable / anon key** ลงในหน้าโปรแกรม (ห้ามใช้ secret / service_role key)
4. ตั้งค่า Authentication ทางอีเมล สมัครบัญชี และเข้าสู่ระบบ
5. เลือกโปรไฟล์ในเครื่องแล้วกด **เรียกคืน/ซิงก์สำเนา** เพื่ออัปโหลดรายการเก่าและเรียกข้อมูลออนไลน์
6. เมื่อต้องการดูจากเครื่องอื่น ให้เข้าสู่ระบบด้วยอีเมลเดียวกันและเลือกโปรไฟล์ชื่อเดียวกัน

ข้อมูลที่เก็บออนไลน์เป็นข้อมูลสำหรับสร้างใบเสร็จใหม่ ไม่ใช่ PDF หรือรูปภาพ และไม่ได้เป็นเอกสารถาวรป้องกันการลบ โปรไฟล์ในเครื่องไม่ใช่ระบบสิทธิ์ผู้ใช้; สิทธิ์ออนไลน์ใช้บัญชี Supabase และนโยบาย RLS

## นำขึ้น GitHub Pages

อัปโหลด `index.html`, `sw.js`, `manifest.webmanifest`, `supabase_schema.sql` และ `README.md` ไปที่ root ของ repository แล้วเปิด Settings → Pages → Deploy from a branch → main / root

**ข้อจำกัด:** ข้อมูลในเครื่องใช้ localStorage ซึ่งมีขนาดจำกัด และการซิงก์อัตโนมัติทำงานเฉพาะขณะที่เปิดหน้าแอปและมีอินเทอร์เน็ต ไม่ใช่การซิงก์เบื้องหลังเมื่อปิดเบราว์เซอร์ หากเคยเปิดเวอร์ชันเก่า ควรรีเฟรชขณะออนไลน์เพื่อรับไฟล์ล่าสุด
