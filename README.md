# โปรแกรมใบเสร็จรับเงินค่าเช่า

- เปิด `index.html` บน GitHub Pages หรือในเบราว์เซอร์
- เลือกหรือสร้างโปรไฟล์ผู้ใช้งาน ก่อนออกใบเสร็จ
- แต่ละโปรไฟล์แยกข้อมูลใบเสร็จ ลำดับเลขที่ และสีแบบฟอร์มในเบราว์เซอร์เดียวกัน
- ข้อมูลเดิม (ถ้ามี) จะอยู่ในโปรไฟล์ **ข้อมูลเดิม** ไม่ถูกลบ
- ใบเสร็จขนาด 17.5 × 8.8 ซม. พิมพ์ A4 แนวตั้งได้ทั้งต้นฉบับและสำเนา
- บันทึกใบเสร็จแล้วถือว่าเสร็จสิ้น สามารถเปิดดูและพิมพ์ย้อนหลัง

**ข้อจำกัด**: โปรไฟล์นี้ไม่ใช่บัญชีออนไลน์ ไม่มีรหัสผ่านและไม่ป้องกันคนอื่นเลือกดูโปรไฟล์กันเอง ข้อมูลอยู่เฉพาะใน localStorage ของเบราว์เซอร์และอุปกรณ์นั้น ไม่ซิงก์ข้ามเครื่อง หากต้องการบัญชีส่วนบุคคลที่ปลอดภัยและใช้ได้ทุกอุปกรณ์ ต้องมีระบบยืนยันตัวตนและฐานข้อมูลออนไลน์เพิ่มเติม

สำรองข้อมูลเป็นไฟล์ JSON แยกตามโปรไฟล์อย่างสม่ำเสมอ
