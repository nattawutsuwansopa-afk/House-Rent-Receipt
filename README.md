# โปรแกรมใบเสร็จรับเงินค่าเช่า

โปรแกรม HTML ภาษาไทยสำหรับกรอกและพิมพ์ใบเสร็จค่าเช่า ทั้งใบเสร็จและสำเนา พร้อมบันทึกรายการย้อนหลัง

## เปิดใช้งานบน GitHub Pages

1. สร้าง Repository ใหม่บน GitHub (เช่น `rent-receipt`).
2. อัปโหลดไฟล์ `index.html` ไปที่รากของ Repository แล้ว Commit.
3. เปิด **Settings → Pages** และตั้ง **Build and deployment → Source: Deploy from a branch**, เลือก **main** และโฟลเดอร์ **/(root)** แล้ว Save.
4. เปิดลิงก์ Pages ที่ GitHub แสดง (ปกติ `https://<username>.github.io/<repository>/`).

## หมายเหตุเกี่ยวกับข้อมูล

- ข้อมูลใบเสร็จบันทึกด้วย `localStorage` ภายในเบราว์เซอร์ของอุปกรณ์ที่ใช้งาน ไม่ได้ซิงก์ผ่าน GitHub หรือระหว่างเครื่อง
- การเปลี่ยนเบราว์เซอร์ อุปกรณ์ หรือชื่อโดเมน อาจทำให้ไม่เห็นข้อมูลเดิม จึงควรใช้ฟังก์ชันสำรอง/นำเข้าข้อมูลของโปรแกรมเป็นระยะ
- ไม่ควรอัปโหลดไฟล์สำรองที่มีข้อมูลผู้เช่าจริงไปยัง Repository สาธารณะ
- เพื่อพิมพ์สีและลวดลายให้ตรงต้นแบบ ให้เปิดการพิมพ์พื้นหลัง (Background graphics) ในหน้าต่างพิมพ์
