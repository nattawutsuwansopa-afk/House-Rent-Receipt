# ใบเสร็จรับเงินค่าเช่า — GitHub Pages / Local Only

## การติดตั้ง
อัปโหลด `index.html`, `sw.js`, `manifest.webmanifest` ลง GitHub repository แล้วเปิด Settings → Pages → Deploy from branch `main`, folder `/ (root)`

## การใช้งาน
- ก่อนเข้าใช้งาน เลือกชื่อผู้ใช้งานที่มีอยู่หรือสร้างชื่อใหม่ ข้อมูลของแต่ละชื่อแยกกันใน **เบราว์เซอร์เครื่องนี้**
- บันทึกใบเสร็จได้แม้ไม่มีอินเทอร์เน็ต เมื่อกดบันทึกจะเปิดดูแบบอ่านอย่างเดียว และสามารถกดแก้ไขภายหลังได้ โดยตรวจเลขที่ซ้ำ พร้อมเตือนหากค่าเช่าเดือนเดียวกันเคยออกใบเสร็จแล้ว
- แก้ไขข้อมูลที่บันทึกแล้ว: เปิดจากประวัติ → กด **แก้ไขใบเสร็จนี้** → ปรับข้อมูล → กด **บันทึกการแก้ไข** หรือ **ยกเลิกการแก้ไข**; ระบบเก็บประวัติการแก้ไขในข้อมูล JSON และคงรหัสใบเสร็จเดิม
- ขนาดใบเสร็จ 17.5 × 8.8 ซม. พิมพ์ต้นฉบับและสำเนาบนกระดาษ A4 แนวตั้ง
- การเก็บคู่สำเนา PDF: กดปุ่ม PDF แล้วเลือก `Save as PDF` ในหน้าต่างพิมพ์
- ต้องกด **สำรองข้อมูล (.json)** แยกตามชื่อผู้ใช้งานเป็นประจำ แล้วเก็บไฟล์ในที่ปลอดภัย การนำเข้าทำผ่านปุ่ม **นำเข้าข้อมูล**
- เปิดใช้งานออฟไลน์ผ่าน GitHub Pages ได้หลังเข้าเว็บออนไลน์ครั้งแรกและติดตั้ง service worker สำเร็จ

## ข้อจำกัดสำคัญ
- GitHub Pages เก็บเฉพาะไฟล์โปรแกรม ไม่ได้รับหรือจัดเก็บใบเสร็จของผู้ใช้งาน
- การเลือกชื่อเป็นการแบ่งข้อมูล ไม่ใช่ระบบยืนยันตัวตนที่ปลอดภัย ไม่มีรหัสผ่าน และผู้ใช้เบราว์เซอร์เดียวกันสามารถเลือกโปรไฟล์อื่นได้
- คนละอุปกรณ์หรือคนละเบราว์เซอร์ไม่เห็นข้อมูลกัน แม้ใช้ชื่อผู้ใช้งานเดียวกัน
- การล้างข้อมูลเว็บไซต์/โหมดไม่ระบุตัวตนอาจทำให้ข้อมูลในเครื่องหาย จึงควรสำรอง JSON
- ไม่ต้องใช้ Supabase, SQL หรือ API key
