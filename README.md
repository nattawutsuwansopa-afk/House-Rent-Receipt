# โปรแกรมใบเสร็จรับเงินค่าเช่า

เปิด `index.html` ในเบราว์เซอร์ หรือเผยแพร่ผ่าน GitHub Pages

- ใบเสร็จขนาด **17.5 × 8.8 ซม.** ต่อใบ
- พิมพ์ต้นฉบับและสำเนาพร้อมกันบน **A4 แนวตั้ง** สเกล 100%
- เปลี่ยนสีแบบฟอร์ม: ชมพู น้ำเงิน เขียว ม่วง น้ำตาล เทา โดยข้อความกรอกเป็นสีดำ
- ค้นหาและกรองประวัติตามชื่อผู้ชำระ พร้อมจำนวนใบเสร็จและยอดรวมต่อบุคคล
- ผู้รับเงินไม่บังคับ, บันทึก/แก้ไข/ลบ, สำรอง/นำเข้าข้อมูล JSON

**การอัปโหลด GitHub:** นำ `index.html` และ `README.md` ลง repository แล้วเปิด Settings > Pages > Deploy from a branch

**ข้อมูลย้อนหลัง:** เก็บไว้เฉพาะ localStorage ของเบราว์เซอร์นั้น ไม่ซิงก์ข้ามเครื่อง ควรสำรองข้อมูลสม่ำเสมอ

**ตั้งค่าพิมพ์:** A4 แนวตั้ง, Scale 100%, ปิด Headers and footers, เปิด Background graphics และตรวจสอบ Preview ก่อนพิมพ์
