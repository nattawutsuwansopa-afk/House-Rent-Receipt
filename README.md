# โปรแกรมใบเสร็จค่าเช่า — Offline + Cloud

## ใช้งาน GitHub Pages
อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ลง repository ที่ root แล้วเปิด Settings → Pages → Deploy from main branch /root

## การออกใบเสร็จ
- ตรวจเล่มที่+เลขที่ซ้ำ (รวมเลขที่ 0001 กับ 1) และจดทะเบียนเลขที่เคยออกแล้ว แม้ลบประวัติจากหน้าเว็บ
- หากคนและบ้านเลขที่เดิมมีใบเสร็จค่าเช่าเดือนและปีเดียวกัน จะแจ้งเตือนให้ยืนยันก่อนออกซ้ำ
- เมื่อกดบันทึกจะล็อกใบเสร็จ ไม่ให้แก้ไขจากแบบฟอร์ม
- ตารางประวัติแสดง ⏳ รอซิงก์ / ✓ สำรองแล้ว / ◌ อยู่ในเครื่อง
- ปุ่ม **บันทึกคู่สำเนา PDF** เปิดหน้าต่างพิมพ์เฉพาะสำเนา ให้ผู้ใช้เลือกปลายทาง **Save as PDF** แล้วจัดเก็บในเครื่องเอง (ไม่ได้เก็บ PDF อัตโนมัติบนคลาวด์)
- ใบเสร็จ 175 × 88 มม. บนกระดาษ A4 แนวตั้ง สเกล 100% ปิดหัวท้ายพิมพ์

## Cloud
สร้าง Supabase project และรัน `supabase_schema.sql` ใน SQL editor, กรอก URL และ anon/publishable key ในเว็บ จากนั้นสมัคร/ล็อกอิน และกดซิงก์
สถานะซิงก์เป็นสถานะการอัปโหลด *ข้อมูลใบเสร็จ* ไม่ใช่ไฟล์ PDF
สำเนารอซิงก์ที่ยังอยู่ใน browser อาจสูญหายหากเคลียร์ข้อมูลเว็บไซต์ ให้สำรอง JSON ด้วย

## ข้อจำกัด
การตรวจเลขซ้ำเป็นระดับโปรไฟล์/อุปกรณ์และข้อมูลที่ดึงลงมาแล้ว ไม่สามารถรับประกันการกันเลขซ้ำที่เกิดพร้อมกันจากหลายอุปกรณ์เมื่อออฟไลน์ได้; ต้องมีฐานข้อมูลกลางกำหนดเลขที่แบบอะตอมิกเพื่อรับประกันทั่วระบบ
โปรไฟล์ที่แยกในเบราว์เซอร์ไม่มีรหัสผ่าน การแบ่งสิทธิ์ออนไลน์เกิดจาก Supabase account และ RLS
PDF สร้างผ่านเครื่องมือ Save as PDF ของเบราว์เซอร์ ไม่ใช่ไฟล์ PDF ที่ระบบจัดเก็บหรือซิงก์อัตโนมัติ

## ป้องกันเลขซ้ำบนคลาวด์
SQL เวอร์ชันนี้เพิ่ม unique index สำหรับคู่เล่มที่+เลขที่ในแต่ละบัญชีและโปรไฟล์ หากออฟไลน์สองเครื่องออกเลขเดียวกันพร้อมกัน ใบเสร็จยังถูกบันทึกในแต่ละเครื่อง แต่รายการที่ซ้ำจะถูกปฏิเสธตอนซิงก์ และคงสถานะรอซิงก์เพื่อแก้ไขต่อ (ใบที่ออกแล้วล็อกไว้ ไม่แก้เลขเอง) ก่อนใช้ index กับข้อมูลเก่าต้องตรวจเลขที่ซ้ำในฐานข้อมูลเดิมก่อน
